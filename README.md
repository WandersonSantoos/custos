# Solicitações Financeiras – Smart Promotora

Interface estática simples e objetiva para centralizar **solicitações internas** da Smart Promotora (Custos de Empresas, Débitos e Recursos Humanos), com redirecionamento para formulários do Google Forms.

## ✨ Visão geral

- **Logo e identidade** da Smart Promotora em destaque.  
- **Links diretos** para três áreas de formulários:
  - Custos Empresas
  - Débitos
  - Recursos Humanos
- **Metadados SMO/OG** para melhor visualização ao compartilhar o link.
- **Rodapé** com ano e crédito do desenvolvedor.
